Overview

About the Project

A responsive, single-page landing design inspired by a Nike website encountered online — built as a captivating landing page concept for a sneaker shop.

Challenge

The Problem

Recreating the confident, image-forward feel of a major sneaker brand's site on a single page, while keeping it fully responsive across screen sizes.

Solution

The Approach

Built a single-page layout using HTML and CSS focused on large product photography, bold typography, and a clean responsive grid — a compact design exercise rather than a full storefront build.
